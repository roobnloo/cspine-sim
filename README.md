# cspine-sim

Simulation code accompanying the manuscript *Convex estimation of Gaussian graphical regression models with covariates*.
The methods are implemented in the `\impl` directory.

## Setup

Install R package dependencies by running:

```r
source("requirements.R")
```

## Running simulations

### 1. Generate data

```bash
./generate-all-data.sh
```

For simplicity, 100 data sets are generated for the $p=25, q=50, n=200$ and $\delta=0$ and $\delta=1$ settings. Additional data sets may be generated by uncommenting the desired line in this script.

### 2. Run simulations

```bash
./run-all.sh
```

For simplicity, runs `cspine` and `RegGMM` on the $p=25, q=50, n=200$ and $\delta=0$ and $\delta=1$ settings. Uncomment the desired lines to run additional settings, after the corresponding data have been generated.

Results are written to the `out/` directory.

### 3. Tables and plots

```bash
Rscript make-tables.R --d=0
Rscript make-tables.R --d=1
Rscript make-plots.R
```

These commands create the tables and figures from the article.
